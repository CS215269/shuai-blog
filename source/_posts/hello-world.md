## 欢迎

这是我的第一篇博客文章，使用 **LaTeX 极简主题**。

这个主题的设计理念来自经典学术论文的排版风格——干净的衬线字体、克制的配色、充裕的留白。暗色模式下像深夜灯下读纸，亮色模式下像翻开一本旧书。

## 特性

- 暗色/亮色主题切换（Ctrl+Shift+T）
- 响应式布局，适配手机、平板、桌面
- 左侧目录自动高亮当前章节
- 键盘无障碍导航

## 关于 Hexo

Hexo 是一个快速、简洁且高效的博客框架。它用 Markdown 解析文章，通过 Nunjucks 模板引擎渲染页面，生成纯静态文件。

```bash
npm install -g hexo-cli
hexo init my-blog
cd my-blog
hexo server
```

写博客就像写笔记一样简单。
